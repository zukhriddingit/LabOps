# Centrifuge Setup (General)

## Before you start
1. Confirm the **rotor type** is installed and rated for your target speed.
2. Confirm the **sample type** so the correct program applies.
3. Always balance the rotor — load tubes in opposing pairs of equal mass.

## Running
1. Set speed and time per the sample-specific SOP (e.g. Cardiovascular Tissue Prep v2).
2. Set temperature (default **4 °C** for tissue).
3. Lock the lid; do not open until the rotor has fully stopped.

## Caution
Never run an unbalanced or unverified rotor. If the rotor type is unknown, stop and confirm
before running.
