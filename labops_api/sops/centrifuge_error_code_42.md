# Centrifuge Error Code 42 — Rotor Imbalance SOP

## Purpose
Respond safely to a rotor imbalance alarm (error code 42) on the centrifuge.

## Escalation Rules
- Stop the run immediately if error code 42 appears.
- Do not restart until the rotor has been inspected and balanced.
- Escalate to the equipment lead if the error recurs after rebalancing.

## Caution
Never open the centrifuge lid while the rotor is spinning. Wait for a full stop before opening.

## Recommended Actions

1. Press the stop button immediately — do not allow the run to continue.
2. Wait for the rotor to come to a complete stop before opening the lid.
3. Open the lid and inspect sample tubes for leakage or breakage.
4. Remove all tubes and check for uneven loading across rotor positions.
5. Rebalance the rotor: ensure opposite positions have equal mass within ±0.1g.
6. Close lid and run a brief test spin at low RPM to confirm balance.
7. Document the incident and corrective action in the equipment log.
8. If the error recurs, remove the unit from service and contact the equipment lead.
