# Inventory Shortage SOP

## Purpose
Manage reagent and consumable shortages to prevent experiment disruption.

## Escalation Rules
- Escalate if a critical reagent is below 2-unit minimum.
- Escalate if an experiment is currently in progress and requires the missing item.

## Caution
Do not substitute reagents without supervisor approval. Confirm item identity before use.

## Recommended Actions

1. Confirm the current stock count — check camera-inferred counts against the physical shelf.
2. Identify which active experiments require the item and their timelines.
3. Check for an alternate stock location (secondary shelf, cold storage, or shared lab supply).
4. If below minimum stock: place a reorder request immediately.
5. Notify the lead researcher if an active run may be affected.
6. Document the shortage event with timestamp and stock count in the inventory log.
7. Update the inventory record once restocked.
