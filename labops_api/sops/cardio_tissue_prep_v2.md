# Cardiovascular Tissue Prep v2

## Scope
Local SOP for preparing cardiovascular tissue samples (e.g. sample C17) for downstream
analysis. Covers cold-chain handling and centrifuge setup.

## Cold-chain limits
- Storage: **-60 °C** (Freezer B).
- Maximum time at room temperature: **20 minutes** before the sample must return to
  controlled storage or proceed to the next step.

## Centrifuge setup checklist
1. Confirm the sample type is cardiovascular tissue.
2. Confirm the **rotor type** matches the tube format (do not run with an unverified rotor).
3. Balance the rotor with a counterweight tube of equal mass.
4. Set speed to **3,000 × g** for **10 minutes** at **4 °C**.
5. Confirm the lid is locked before starting.

## Caution
Confirm sample type and rotor type before running. If the rotor is unverified, stop and
check with a postdoc — running an unbalanced or mismatched rotor is a safety hazard.
